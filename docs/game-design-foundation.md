# 보카로 카드게임 기초 기획서 (v0.1)

> 컨셉: **보카로P = 룰(정체성) 카드**, **보카로 곡 = 스킬(액션) 카드**

---

## 1. 컨셉을 다시 정리하면

- 플레이어는 "보카로P"가 되어 게임을 한다.
- P는 게임 내내 필드에 고정으로 존재하는 **룰/정체성 카드**로, 그 P만의 특성(패시브/액티브 능력, 덱 제한)을 부여한다.
- P가 낸 "곡"들은 **손패에서 코스트를 내고 발동하는 스킬 카드**다.
- 즉 이 게임은 "**고정된 정체성 카드 1장 + 그 정체성이 규정하는 덱**" 구조다.

이 구조는 카드게임 역사에서 이미 여러 번 검증된 패턴이라, 완전히 새로 만들 필요 없이 **가장 잘 맞는 기존 프레임을 골라 변형**하면 빠르게 기초가 잡힌다.

---

## 2. 유명 카드게임 비교

| 게임 | 핵심 루프 | 자원 시스템 | "정체성 카드" 유무 | 복잡도 | 우리 컨셉과의 적합성 |
|---|---|---|---|---|---|
| **매직 더 개더링(MTG)** | 랜드로 마나 확보 → 크리처/주문 전개 → 전투 | 색상별 마나(랜드) | 없음(덱 색상 조합으로 대체) | 높음 | 낮음 — 색상 시스템이 P 개성보다 우선됨 |
| **하스스톤** | 직업(Hero) 선택 → 매턴 +1 마나 → 카드 전개 → 직업 파워 사용 | 단일 마나(1→10) | **있음** (Hero + Hero Power) | 낮음~중간 | **높음** — Hero=P, Hero Power=P 고유 스킬 |
| **유희왕** | 몬스터 소환/일반소환 → 마법/함정 → 전투 데미지 | 없음(소환권으로 대체) | 없음 | 매우 높음 | 낮음 — 룰이 복잡하고 정체성보다 콤보 위주 |
| **도미니언(덱빌딩)** | 공용 시장에서 카드 구매 → 덱 압축/개선 | 처리(Treasure) 카드 | 없음 | 중간 | 낮음 — 곡을 "고르는" 재미는 있지만 P 개성이 옅음 |
| **러브레터** | 16장 미니덱, 매턴 1장 드로우 후 1장 플레이, 추리/탈락 | 없음 | 없음 | 매우 낮음 | 중간 — 가볍지만 "곡" 하나하나의 존재감이 약해짐 |
| **카드파이트!! 뱅가드 / 바이스슈발츠** | "리더/뱅가드" 캐릭터가 필드에 실물로 존재, 라이드(성장)하며 다른 카드로 서포트 | 카운터/트리거 체크 | **있음** (캐릭터 자체가 카드) | 중간 | 높음 — 캐릭터=곡/아이돌 비유가 자연스러움 |
| **마블 챔피언스/L5R 등 LCG(리빙카드게임)** | 정해진 "아이덴티티(리더)" 카드가 덱 제한·고유 능력 부여, 나머지는 덱빌딩 | 자원 카드 또는 고정 자원 | **있음** (Identity/Leader) | 중간 | **매우 높음** — "리더가 룰을 정하고 덱은 그 룰 아래서 구성"이 정확히 P=룰 컨셉 |

### 결론
**하스스톤의 "Hero + Hero Power + 마나 커브"** 와 **LCG류(마블 챔피언스, L5R)의 "Identity 카드가 덱 제한/고유 능력을 부여"** 구조가 컨셉과 가장 정확히 겹칩니다. 여기에 **카드파이트!! 뱅가드의 "캐릭터가 실물로 필드에 존재"** 하는 연출감을 더하면, "P가 무대 위에서 곡을 발표한다"는 테마가 살아납니다.

→ **최종 베이스: LCG형 Identity 시스템 + 하스스톤형 단일 자원 커브를 결합한 하이브리드**로 기초를 세웁니다.

## 3. 기초 게임 구조

### 3.1 플레이어 구성
- **P 카드 (Producer / Rule) 1장**: 게임 시작 시 선택, 게임 내내 필드에 고정. 셔플되지 않음.
- **곡 덱 (Song Deck) 30~40장**: P 카드가 정한 "소속 규정"에 맞춰 구성.
  - 예: "이 덱에는 [해당 P] 명의 곡만 넣을 수 있고, 무소속(커버/편곡) 곡은 최대 5장까지 혼합 가능"
- **인기도 (Popularity, 생명치)**: P 카드마다 기본값이 다름 (예: 18~24). 0이 되면 패배.

### 3.2 자원: 재생 포인트 (Play Point, PP)
- 하스스톤 마나처럼 **매 턴 +1, 최대 10**까지 자동 증가하는 단일 자원.
- 테마상 "스트리밍 조회수가 쌓여 다음 곡을 낼 여력이 생긴다"는 플레이버.

### 3.3 카드 타입 (곡 카드 = 스킬 카드)
| 타입 | 아이콘 성격 | 역할 |
|---|---|---|
| **보컬 (Vocal)** | 공격형 | 상대 인기도 감소 / 직접 데미지 |
| **서포트 (Support)** | 버프·디버프 | 자신 강화 또는 상대 약화, 지속 효과 |
| **스토리 (Story)** | 설치형 | 필드에 남아 매 턴 효과를 발동 (세계관형 곡) |
| **코러스 (Chorus)** | 반응형 | 상대 턴에도 즉시 사용 가능 (MTG 인스턴트/하스스톤 비밀 포지션과 유사) |

### 3.4 턴 순서
1. **인트로(시작)**: 턴 시작 트리거 정산
2. **드로우**: 곡 카드 1장 드로우
3. **차지**: 재생 포인트 +1 (최대 10)
4. **메인**: 손패의 곡 카드 발동(플레이), P 카드의 액티브 능력 사용 가능
5. **무대(전투)**: 발동한 보컬 카드로 상대 인기도 감소 처리
6. **엔딩**: 턴 종료 트리거 정산, 상대에게 코러스 반응 기회 부여 후 턴 넘김

### 3.5 승리 조건 (두 가지 모드 제안)
- **배틀 모드**: 상대 인기도를 0으로 만들면 승리 (대전형, 하스스톤식)
- **차트 모드**: 정해진 턴(예: 10턴) 종료 시 인기도 합산 최고 점수 승리 (비파괴 경쟁형, 러브레터처럼 짧게 즐기기 좋음)

## 4. P 카드(룰카드) 설계 템플릿

P 카드는 다음 4가지 요소로 구성합니다.

1. **소속 규정 (Deck Restriction)**: 어떤 곡을 덱에 넣을 수 있는지
2. **패시브 (Passive)**: 상시 발동되는 특성 (해당 P의 음악적 색깔 반영)
3. **액티브 (Active)**: PP를 소모해 턴당 1회 발동하는 고유 스킬 (Hero Power 역할)
4. **기본 인기도 (Base Popularity)**: 생명치

### 예시 P 카드 3종 (형식 시연용, 밸런스는 추후 조정)

> ※ 실존 인물/곡명을 예시로 들었습니다. 개인 팬 기획/플레이테스트 용도로는 통용되는 방식이지만, **정식 출시/상업화를 고려한다면 실명·곡명 사용에 대한 저작권/라이선스 검토가 필요**합니다. 필요하시면 가상의 P 이름으로 치환한 버전도 만들어 드릴 수 있어요.

**① kz (livetune) — 장르: EDM/퓨처베이스**
- 소속 규정: kz 곡 + 무소속 최대 5장
- 패시브: "EDM 속성 곡 카드의 재생 비용 -1"
- 액티브 (PP 3, 턴당 1회): "덱 위 2장을 확인 후 1장 손으로"
- 기본 인기도: 22

**② DECO*27 — 장르: 팝/록**
- 소속 규정: DECO*27 곡 + 무소속 최대 5장
- 패시브: "'고백' 태그 곡 카드 발동 시 상대 인기도 추가 1 감소"
- 액티브 (PP 4, 턴당 1회): "무덤의 곡 카드 1장을 손으로 되돌린다"
- 기본 인기도: 20

**③ 하치(요네즈 켄시 명의) — 장르: 문학적 록**
- 소속 규정: 하치 곡 + 무소속 최대 5장
- 패시브: "스토리형 카드가 필드에 2장 이상이면 매 턴 인기도 1 회복"
- 액티브 (PP 5, 턴당 1회): "스토리형 곡 카드 1장을 손에서 즉시 설치(비용 무시)"
- 기본 인기도: 24 (느린 대신 스토리 시너지형)

## 5. 곡 카드(스킬 카드) 프레임 제안

```
┌─────────────────────────┐
│ [자켓아트]                │
│                          │
│ 곡명 (카드명)      비용: ● │
│ 유형: 보컬/서포트/스토리/코러스│
│ 소속: [P명]               │
│ ─────────────────────── │
│ 효과 텍스트               │
│ ─────────────────────── │
│ "가사 한 소절" (플레이버)   │
└─────────────────────────┘
```

- **레어도 = 실제 흥행 규모**로 테마를 살리면 카드게임 특유의 "체감 파워"와 자연스럽게 연결됩니다.
  - 커먼(C): 스트리밍 스테디셀러
  - 레어(R): 밀리언 히트
  - 레전더리(L): "전설의 명곡" 급, 강력한 1장짜리 효과 + 낮은 채용 매수 제한(덱당 1장)

## 6. 밸런스 가이드라인 (초안)

| 비용(PP) | 보컬 데미지 기준 | 비고 |
|---|---|---|
| 1 | 1~2 | 견제용 |
| 2 | 2~3 | |
| 3 | 3~4 | |
| 4 | 4~6 + 부가효과 1개 | |
| 5+ | 6~8 + 부가효과 또는 필드 전체 효과 | 레전더리 급 |

- 서포트/스토리 카드는 데미지 대신 "효과 강도"를 위 표의 데미지 값에 준해 환산.
- P의 패시브가 특정 속성을 강화하므로, 그 속성 카드의 순수 수치는 살짝 낮추고 시너지에서 이득을 보게 설계(하스스톤의 직업 카드 하향 원칙과 동일).

## 7. 다음 단계 제안

1. **프로토타입 카드 20~30장** 제작 (P 3명 × 곡 8~10장 수준)
2. 종이 프로토타입으로 **1:1 플레이테스트** (배틀 모드부터)
3. 승률/평균 턴 수/체감 파워 밸런스 조정
4. 이후 확장: P 간 "콜라보 곡"(2개 소속 카드), 트리거 체크(뱅가드식 즉석 효과) 등 추가 시스템 검토

---

### 이 구조를 고른 이유 요약
- **하스스톤형 단일 자원 커브** → 룰이 단순해 진입장벽이 낮음
- **LCG형 Identity 카드** → "P가 룰을 정한다"는 컨셉을 기계적으로 정확히 구현
- **뱅가드식 캐릭터 실재감** → P 카드가 계속 필드에 남아있어 "무대 위의 P" 테마가 시각적으로 유지됨
- **레어도=흥행 규모** → 보카로 문화 특유의 "명곡 서사"를 카드 파워와 자연스럽게 연결
