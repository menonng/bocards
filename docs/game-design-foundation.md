# 보카로 카드게임 기초 기획서 (v0.2)

> 컨셉: **보카로P = 게임 전체에 적용되는 공용 특수규칙 카드**, **보카로 곡 = 스킬(액션) 카드**

> **v0.2 변경점**: P 카드를 "플레이어 개인이 고르는 정체성(Hero/Identity)"에서 **"게임 시작 시 공개되어 모든 플레이어에게 동일하게 적용되는 공용 규칙 카드"**로 구조 변경. (v0.1은 하스스톤/LCG형 개인 정체성 모델이었음 — 기록용으로 하단에 남겨둠)

---

## 1. 컨셉을 다시 정리하면

- P 카드는 **어느 한 플레이어의 것이 아니다.** 게임 시작 시 테이블 중앙에 공개되어 **모든 플레이어가 동일하게 그 규칙 아래서 플레이**한다.
- 즉 P는 "이번 판이 어떤 판인지"를 정하는 **하우스룰/세계관 카드**에 가깝다. (예: "이번 판은 kz의 EDM 시대다 → 전원 자원 회복이 빨라진다")
- 곡 카드(스킬 카드)는 기존과 동일하게 플레이어 개인 손패/덱에서 코스트를 내고 쓰는 액션 카드.
- 구조: **"공용 규칙 1(~3)장 + 개인 곡 덱"**

---

## 2. 이 구조의 유명 카드게임 선례

"한 장의 카드가 특정 플레이어 소유가 아니라 **테이블 전체에 동시에 적용**된다"는 메커니즘은 이미 여러 유명 게임에 있다.

| 게임 | 메커니즘 | 특징 | 우리 컨셉과의 유사점 |
|---|---|---|---|
| **유희왕 — 필드 마법 카드(Field Spell)** | 필드 존에 카드 1장을 놓으면 **양쪽 듀얼리스트 모두**에게 적용되는 상시 효과 발동. 새 필드 마법이 나오면 기존 것을 대체. | 소유자는 있지만 효과는 공용. 1장만 유지, 교체 가능. | 가장 근접한 선례. "하나의 카드 = 판 전체의 규칙" |
| **매직 더 개더링 — 플레인체이스(Planechase) 변형 룰** | 테이블 중앙에 "차원(Plane) 카드" 1장이 항상 공개되어 있고, 그 판 전체(전원)에 적용되는 룰/효과를 부여. 특정 트리거(주사위)로 다른 차원으로 전환. | 완전 공용, 소유자 없음. 세계관 연출이 강함. | "이번 판의 세계관 = 규칙"이라는 발상이 정확히 일치 |
| **Fluxx** | "New Rule" 카드를 계속 내려놓아 **게임 전체의 규칙**(손패 제한, 낼 수 있는 카드 수 등)을 실시간으로 계속 바꿈. | 여러 규칙이 누적/교체되며 판이 계속 변형됨. | "규칙 자체가 카드"라는 발상의 원조 |

### 결론
**유희왕의 필드 마법(공용 1장 유지) + 플레인체이스의 세계관 연출(전원에게 적용되는 분위기)**을 베이스로 삼고, 필요하면 **Fluxx식으로 여러 장을 겹쳐서** 리플레이성을 더하는 구조를 추천합니다.

→ **P 카드 = "무대 카드(Stage Card)"**: 게임 시작 시 1~2장이 공개되어 테이블 중앙(무대)에 놓이고, 게임이 끝날 때까지 전원에게 동일하게 적용된다.

---

## 3. 기초 게임 구조 (v0.2)

### 3.1 셋업
1. P 카드 덱(전체 보카로P 목록)에서 **1~2장을 무작위 공개** (또는 플레이어 합의로 드래프트) → 테이블 중앙 "무대" 존에 배치.
2. 공개된 P 카드(들)의 텍스트를 전원이 확인. **이 규칙은 게임이 끝날 때까지 유지**된다 (기본 모드 기준).
3. 각 플레이어는 자신의 곡 덱(30~40장)을 준비. **더 이상 특정 P 소속으로 덱을 제한하지 않는다** — 자유롭게 구성.
   - 단, 곡 카드에는 원곡의 "소속 P" 태그가 남아있어 무대 카드와의 **시너지 판정**에 쓰인다. (3.3 참고)
4. 인기도(생명치) 초기값은 무대 카드가 조정한 기본값을 따름 (예: 기본 20, 무대 카드가 ±로 수정).

### 3.2 자원: 재생 포인트 (Play Point, PP)
- 매 턴 +1, 최대치는 **무대 카드가 정한 값**을 따름 (기본 10, 무대 카드로 조정 가능).

### 3.3 무대 시너지 (신규)
- 발동한 곡 카드의 "소속 P"가 **현재 무대에 공개된 P 카드와 같으면**, 소소한 보너스 발생 (예: 비용 -1, 데미지 +1 등 — 곡 카드 자체에 "무대 보너스" 텍스트로 명시).
- 이렇게 하면 무대 카드가 곡 카드를 강제로 제한하지 않으면서도, "이 무대엔 이 P 곡이 잘 어울린다"는 테마적 재미와 약한 덱 방향성을 동시에 줄 수 있음.

### 3.4 카드 타입 (곡 카드 = 스킬 카드) — 기존과 동일
| 타입 | 역할 |
|---|---|
| **보컬 (Vocal)** | 상대 인기도 감소 |
| **서포트 (Support)** | 버프·디버프 |
| **스토리 (Story)** | 설치형 지속 효과 |
| **코러스 (Chorus)** | 상대 턴에도 반응 가능 |

### 3.5 턴 순서 — 기존과 동일
드로우 → 자원 차지 → 메인(카드 발동) → 무대(전투) → 엔딩

### 3.6 승리 조건
- **배틀 모드**: 상대 인기도 0 → 승리
- **차트 모드**: 정해진 턴 종료 시 인기도 최고 → 승리
- (무대 카드가 이 승리 조건 자체를 바꾸는 것도 가능 — 예: "이 무대에서는 카드를 가장 많이 발동한 플레이어가 보너스 점수")

### 3.7 (확장 옵션) 무대 전환
- 기본은 "고정"이지만, 확장 룰로 **"앙코르(Encore)" 이벤트 카드**를 곡 덱에 소량 섞어, 발동 시 무대 카드를 다른 것으로 교체(유희왕 필드 마법 교체 / MTG 플레인워크와 동일한 발상)하는 것도 가능. 판마다 분위기가 바뀌는 재미를 원하면 이후 확장으로 추가.

## 4. 무대 카드(P 카드) 설계 템플릿

P 카드는 다음 요소로 구성합니다. (더 이상 "소유자"나 "액티브 스킬"은 없음 — 순수하게 판 전체의 상시 규칙)

1. **테마명**: 그 P의 음악적 색깔을 규칙으로 은유
2. **글로벌 효과 1~2개**: 전원에게 적용되는 상시 규칙 수정
3. **기본값 조정**: 인기도 초기값 / PP 최대치 / 덱 매수 등 세팅값 변경 (선택)

### 예시 무대 카드 4종 (형식 시연용)

> ※ 실존 인물/곡명은 팬 기획·플레이테스트용 예시입니다. 상업화 시 별도 저작권 검토가 필요합니다.

**① kz (livetune) — "네온 시티 팝"**
- 전원의 PP 최대치 +2 (최대 12)
- 대신 전원의 시작 인기도 -3
- *(하이템포 EDM처럼 자원은 빨리 돌지만, 판이 짧고 화끈하게 끝남)*

**② DECO*27 — "고백의 계절"**
- 서포트 타입 곡 카드의 효과가 전원에게 +1 강화
- *(감정을 직설적으로 던지는 가사처럼, 버프/디버프가 더 진하게 걸림)*

**③ 하치 — "긴 이야기"**
- 스토리 타입 카드의 지속 턴 +1
- 게임 종료 기준 턴 수 +2 (차트 모드일 때)
- *(서사적인 곡답게, 판 자체가 길어지고 설치형 카드가 강해짐)*

**④ Neru — "디지털 리터러시"**
- 전원 매 턴 카드 1장 추가 드로우
- 대신 전원 손패 제한 -1
- *(정보 과잉·소모전 컨셉 — 카드를 빨리 돌리되 쌓아두진 못함)*

## 5. 곡 카드(스킬 카드) 프레임 제안

```
┌─────────────────────────┐
│ [자켓아트]                │
│                          │
│ 곡명 (카드명)      비용: ● │
│ 유형: 보컬/서포트/스토리/코러스│
│ 소속: [P명] (무대 시너지용)  │
│ ─────────────────────── │
│ 효과 텍스트               │
│ 무대 보너스: (소속 일치 시) │
│ ─────────────────────── │
│ "가사 한 소절" (플레이버)   │
└─────────────────────────┘
```

- **레어도 = 실제 흥행 규모**로 테마 유지: 커먼(스테디셀러) / 레어(밀리언 히트) / 레전더리(전설의 명곡, 덱당 1장 제한)

## 6. 밸런스 가이드라인 (초안)

| 비용(PP) | 보컬 데미지 기준 | 비고 |
|---|---|---|
| 1 | 1~2 | 견제용 |
| 2 | 2~3 | |
| 3 | 3~4 | |
| 4 | 4~6 + 부가효과 1개 | |
| 5+ | 6~8 + 부가효과 또는 필드 전체 효과 | 레전더리 급 |

- 무대 카드는 **개별 카드가 아니라 판 전체의 배율/기본값**을 건드리므로, 카드 자체 밸런스와 별개로 **무대별 파워 밸런스 테스트**가 따로 필요함 (예: "고백의 계절" 무대에서 서포트 카드가 과하게 강해지지 않는지).
- 무대 시너지 보너스(3.3)는 크지 않게: 비용 -1 또는 수치 +1 수준 권장 (강제 제한이 없는 대신 보너스가 크면 사실상 제한처럼 작동해버림).

## 7. 다음 단계 제안

1. **무대 카드 5~6종 + 곡 카드 20~30장** 제작
2. 무대 카드를 매번 바꿔가며 **1:1 플레이테스트** → 같은 곡 덱이라도 무대에 따라 게임이 달라지는지 확인
3. 무대 카드 효과가 너무 강해서 "그 판은 항상 이런 전략만 쓴다"가 되지 않는지 체크 (다양성 확보가 핵심 밸런스 지표)
4. 확장: 무대 카드 2장 동시 공개(Fluxx식 중첩), 앙코르(무대 전환) 이벤트 카드

---

### 이 구조를 고른 이유 요약
- **유희왕 필드 마법** → "한 장이 전원에게 적용된다"는 정확한 메커니즘 선례
- **MTG 플레인체이스** → "이번 판의 세계관 = 규칙"이라는 연출 컨셉의 선례
- **Fluxx** → 규칙 카드 자체를 게임의 핵심 재미로 삼는 발상
- 이 조합으로 "보카로P가 이 판의 분위기/시대를 정한다"는 테마가 개인 정체성보다 더 정확하게 구현됨
- 곡 카드는 소속 P 태그만 남기고 자유 덱빌딩 + 무대 시너지 보너스로, 강제 제한 없이도 테마 일관성을 살릴 수 있음

## 부록: v0.1 기록 (개인 정체성 모델, 폐기)

v0.1에서는 P 카드를 하스스톤 Hero + LCG Identity처럼 **플레이어 개인이 선택하고 그 아래서 덱을 제한**하는 모델로 설계했었음. 이번 피드백으로 "P는 개인 정체성이 아니라 판 전체의 공용 규칙"이라는 방향으로 전환함. 개인 정체성 시스템이 다시 필요해지면(예: "무대와는 별개로 플레이어별 개성도 원한다") v0.1 구조를 별도 레이어로 재활용 가능.
